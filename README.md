
# Business Analytics Assignments

## About This Repository

This repository contains my Business Analytics coursework and practical assignments completed as part of my BCA studies. It includes Power BI reports, PDF assignment documents, and organized assignment folders.

The objective is to develop practical skills in data analysis, data visualization, business intelligence, and communicating insights from data.

## How to Access the Files

### View Power BI Reports

1. Download the required `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file in Power BI Desktop.
4. Explore the report pages, filters, charts, and other interactive visuals.

Official download: https://powerbi.microsoft.com/desktop/

### View PDF Assignments

Open a PDF file directly on GitHub or download it to read the assignment instructions and supporting material.
